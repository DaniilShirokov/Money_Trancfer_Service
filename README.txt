README для Transfer Money API
Этот документ представляет собой описание спецификации API для перевода денег с карты на карту и подтверждения операций. API реализован согласно спецификации OpenAPI 3.0.0 и предназначен для использования в финтех-приложениях.

Общая информация

Название API: Transfer Money API

Версия API: 1.0.0

Описание: API предоставляет возможность осуществления перевода денег между картами, а также подтверждения этих операций.
Сервер

URL сервера: http://localhost:5500/transfer

Описание: Локальный сервер для тестирования и разработки.
Эндпоинты
1. Перевод средств

URL: /transfer
Метод: POST
Описание: Отправка денег с одной карты на другую.
Запрос	Тело запроса должно содержать следующие поля:
cardFromNumber	Номер карты отправителя (строка)
cardFromValidTill	Срок действия карты отправителя (строка)
cardFromCVV	CVV-код карты отправителя (строка)
cardToNumber	Номер карты получателя (строка)
amount	Объект с данными о сумме перевода:
    - value	Сумма перевода (целое число)
    - currency	Валюта перевода (строка)
Ответы
200: Успешный перевод. Возвращает объект с полем operationId.
400: Ошибка ввода данных. Возвращает сообщение об ошибке и идентификатор.
500: Ошибка перевода. Возвращает сообщение об ошибке и идентификатор.

2. Подтверждение операции
URL: /confirmOperation
Метод: POST
Описание: Подтверждение проведенной операции с помощью кода. 
Запрос	Тело запроса должно содержать следующие поля:
operationId	Идентификатор операции (строка)
code	Код верификации (строка)
Ответы
200: Успешное подтверждение. Возвращает объект с полем operationId.
400: Ошибка ввода данных. Возвращает сообщение об ошибке и идентификатор.
500: Ошибка подтверждения. Возвращает сообщение об ошибке и идентификатор.
